# YieldLens v2 Implementation Plan — Overview and Shared Interfaces

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the autonomous multi-agent fix-or-float desk described in the spec, as four parallel lanes that meet at the interfaces defined here.

**Architecture:** Two ERC-4626 vaults plus an `AgentRouter` on Arbitrum Sepolia; a LangGraph desk that decides a target fixed/floating split and executes per-user moves through the router; a FastAPI service and React UI around it; Dune for the track record.

**Tech Stack:** Solidity 0.8.24 + Foundry + OpenZeppelin 5.1; Python 3.12 + LangGraph + Pydantic v2 + web3.py + httpx + FastAPI; React 18 + Vite + TypeScript + wagmi v2 + RainbowKit + viem; Dune.

**Spec:** `docs/superpowers/specs/2026-10-03-yieldlens-agentic-design.md`

### API endpoints (C1)

`POST /desk/run → {run_id}` (409 if a run is active) · `GET /desk/runs/{run_id}/events` (SSE, events `node_start`, `node_end`, `done`, `error`, each `data` is JSON `{node, run_id, ...}`) · `GET /desk/latest → DeskReport` (404 if none) · `GET /desk/runs/{run_id} → DeskReport` · `GET /health → {"ok": true}`.

## Review Focus

Inputs the spec implies but no happy path covers; each has a pinned test in the named task.

1. A delegated user with zero balance in both vaults: `moveFor` must revert `ExceedsCap`, and the executor must skip them with reason `"no_balance"` before sending anything. (A4, B8)
2. A user who revoked the router's share allowance after delegating: `moveFor` reverts inside the vault; the executor must detect the missing allowance and skip with reason `"no_allowance"`. (B8)
3. Moving 100% of a position: `withdraw(assets)` can round up to more shares than the user holds; the router must take the `redeem(all shares)` path when `assets` equals the user's full balance in `fromVault`. (A4)
4. Pendle market expired or expiring within 14 days: Risk Officer must force `target_fixed_bps = 0` regardless of the LLM's answer. (B4)
5. Two "Convene desk" clicks in a row: the second `POST /desk/run` must return 409 and not start a second graph. (C1)
